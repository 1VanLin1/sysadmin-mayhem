# 🖥️ SysAdmin Mayhem — Мультиплеерный 2D-симулятор сисадминов

**SysAdmin Mayhem** — это мультиплеерный экшен-симулятор дата-центра в реальном времени с поддержкой кооперативного и соревновательного режимов, системой авторизации, глобальным лидербордом и сбалансированным AI-напарником Васильичем.

---

## 🌟 Ключевые возможности

### 1. 🔐 Авторизация и профиль сисадмина
- Полноценная регистрация и вход по никнейму и паролю (хэширование SHA-256 с индивидуальной солью).
- Локальная база данных `server/database.json`.
- Сохранение личной статистики: Рекорд XP, Всего устраненных аварий, Число побед.
- Возможность играть как под своим аккаунтом, так и в быстром гостевом режиме.

### 2. 🏆 Глобальный лидерборд дата-центра
- Кнопка **«Таблица лидеров»** в главном меню (`GET /api/leaderboard`).
- Топ сисадминов ранжируется по рекорду очков XP, общему числу починок и побед в дуэлях.
- Подсветка текущего профиля в списке.

### 3. ⚖️ Сбалансированный Васильич (AI-напарник)
- **Устранена проблема «супер-админа»**: скорость ремонта Васильича сбалансирована до `2.0` за тик (у игрока базовая скорость `2.6`, а при способности Оверклок — `6.5`).
- Добавлена задержка осмотра/диагностики (0.24 сек) перед началом починки, благодаря чему внимательный игрок всегда успевает взять инициативу.
- Васильич является надежным командным помощником в Кооперативе и достойным соперником в PvP, но больше не забирает все задачи у игрока за секунду.

### 4. 🔄 Исправление переключения режимов комнат
- Исправлен баг, при котором комната оставалась заблокированной в кооперативе.
- При повторном входе в комнату или начале новой игры режим корректно переключается на выбранный (Кооператив или PvP).

### 5. 🚪 Выход из игры и механика поражения
- **В соревновательном режиме (PvP)**:
  - Добавлена кнопка **«🏳️ Сдаться»** в верхней панели.
  - При подтверждении игрок признает поражение, а сопернику досрочно присуждается победа и премия.
- **В кооперативном режиме (Co-op)**:
  - Добавлена кнопка **«🚪 Выйти»**.
  - При одиночной игре смена завершается мгновенно.
  - При игре вдвоем напарнику отправляется запрос на согласование: досрочный выход происходит только при подтверждении обоими сисадминами.

### 6. 🌲 Серверная и Внутренний двор дата-центра
- Индор-зона: серверные стойки, рубильник питания, верстак сборки серверов, терминал NOC.
- Аутдор-зона: Спутниковая тарелка магистрального линка, Аварийный Дизель-генератор, Градирня чиллера.
- Навигационный шлюз-дверь для перемещения между серверной и улицей.

### 7. ⚡ Активные способности с кулдауном
- `[R]` — **Турбо-спринт**: +60% к скорости бега.
- `[F]` — **Оверклок**: 2.5x ускорение сборки и ремонта.
- `[C]` — **Саботаж (только в PvP)**: замедляет оппонента на 50%.
- Горячие клавиши `1-5` для быстрого выбора инструментов.

---

## 🚀 Запуск проекта

```bash
# Установка зависимостей
npm install

# Запуск сервера (порт 3002)
node server/index.js
```

Игра доступна в браузере: **http://localhost:3002**
